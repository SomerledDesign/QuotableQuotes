# Quoteable Quotes v1.0.1

Maintenance release focused on the Kevin Samuels quote library and proposed-font controls.

## Download

Download the attached release asset:

- `QuoteableQuotes-v1.0.1.saver.zip`

## What's Changed

- Added `kevin-samuels-quotes.xml`, a 200-entry bundled quote library of paraphrased Kevin Samuels-themed aphorisms.
- Registered the Kevin Samuels library in both the standalone app and the macOS `.saver` options.
- Fixed saver quote loading for the Kevin Samuels bundle, including saved theme-key normalization and the previous `kevin-samauels` misspelling.
- Updated the saver XML parser to consume `<theme>` metadata consistently with the standalone app.
- Cleared stale saver quote decks before reloads so failed loads cannot leave old quote content active.
- Added a persisted `Use Proposed Font?` setting so XML `<font>` suggestions can be enabled or disabled.
- Replaced the checkbox-style proposed-font control with a left-justified label, grey proposed-font name, and real switch control.
- Displayed the active proposed font name beside the switch, including `Avenir Next Condensed` for the Kevin Samuels pack.
- Improved font resolution so both exact font names and font families are attempted before falling back to the system font.
