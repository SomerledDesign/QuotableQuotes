# Quoteable Quotes v1.0.0

Initial usable macOS screen saver release.

## Download

- `QuoteableQuotes-v1.0.0.saver.zip`

## What's Included

- Native macOS `.saver` bundle.
- Standalone Swift/AppKit preview app.
- Shared XIB-backed options UI for the app and saver.
- Bundled XML quote libraries:
  - Mixed
  - Generic
  - Leadership
  - Stoicism
  - Comedic
  - Greek Philosophers
  - French Revolutionaries
- Bundled parchment/paper/fabric background images.
- Custom quote XML file support.
- Custom background image support.
- Font, color, size, timing, animation, and attribution options.
- Randomized quote order with no repeats until the selected library is exhausted.
- Per-quote XML font suggestions, with user-selected font fallback.

## Install

See [Installation](../wiki/Installation.md).

Quick install from source:

```bash
scripts/build-saver.sh
scripts/install-saver.sh
```

## Validation

Release validation for this build:

```bash
scripts/compile-options-xib.sh
swift build -c release
swift test
scripts/build-saver.sh
```

## Notes

- The saver bundle is ad-hoc signed for local installation/testing.
- The generated bundle is `dist/QuoteableQuotes.saver`.
- The release zip should be generated from that bundle as `dist/QuoteableQuotes-v1.0.0.saver.zip`.
